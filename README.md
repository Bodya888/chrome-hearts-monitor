# Chrome Hearts Monitor

Бесплатно работает на GitHub Actions: каждые ~5 минут проверяет chromehearts.com и присылает письмо, когда:

1. **На главной появляется дроп.** Главная сейчас пустая. Во время дропа сайт вставляет в неё товары скрытыми блоками `js-homepage-product-wrapper`, а скрипт главной их проявляет. Монитор узнаёт эти блоки, открывает страницу товара и присылает название, цену, фото и ссылку. Если на главной изменится что-то ещё (баннер, текст, ссылка), придёт письмо «Главная страница изменилась».
2. **Открывается скрытый раздел.** Сейчас 34 выключенных раздела (hoodie, sweatshirt, t-shirt, jacket, denim, hat, beanie, belt, eyewear, shoes и другие, плюс старый URL худи «1988») перенаправляют на главную. Как только раздел начинает показывать содержимое, приходит письмо.
3. **Появляется новый товар или sold-out товар возвращается в наличие** в обычном каталоге.

## Настройки (GitHub → Settings → Secrets and variables → Actions)

| Secret | Значение |
|---|---|
| `SMTP_USER` | iCloud-адрес, с которого и на который приходят письма |
| `SMTP_PASSWORD` | пароль приложения: appleid.apple.com → «Вход и безопасность» → «Пароли приложений» |
| `EMAIL_TO` | необязательно: другой адрес получателя (можно несколько через запятую) |

Переменная `WATCH_PATHS` (вкладка *Variables*) задаёт дополнительные адреса для слежки через запятую, например `hoodie/some-hoodie/123456BLKXXX001.html`.

## Управление

- **Пробное письмо:** вкладка Actions → *Chrome Hearts monitor* → *Run workflow* → отметить *Send a test email*.
- **Лог проверок:** вкладка Actions, любой запуск.
- **Остановить:** Actions → *Chrome Hearts monitor* → `···` → *Disable workflow*.
- Состояние (что уже видели) хранится в `state.json` и коммитится только при изменениях на сайте.

## Запуск локально (необязательно)

```bash
cp .env.example .env    # вписать SMTP_USER и SMTP_PASSWORD
python3 monitor.py --list         # что сейчас видно на сайте
python3 monitor.py --test-email   # пробное письмо
./install.sh                      # фоновая проверка на Mac каждые 2 минуты
```

## Ограничения

- GitHub запускает расписание не чаще раза в 5 минут, а в часы нагрузки бывают задержки на 5–15 минут.
- Как выглядит главная во время дропа, проверено по коду сайта, а не на живом дропе. На случай другой вёрстки есть запасной сигнал «Главная страница изменилась».
